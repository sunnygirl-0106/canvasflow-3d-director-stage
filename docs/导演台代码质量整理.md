# 导演台代码质量整理

在视觉优化提交 `4fe02f4` 后单独整理，便于审查与回退。本次集中处理变动频繁的 UI、构图和公共创建入口，没有迁移框架或重写动画/文档/AI 执行链。

- 清除全局样式 16 条、时间轴样式 19 条已被同选择器后续规则覆盖的声明，保留原层叠次序与媒体查询边界。默认 1920×1080 整页截图与整理前比较为 0 像素差异，证据：`test-output/quality/visual-comparison.json`。
- AI 面板显式初始化会话展示标志，草稿通过 `renderInput(draft)` 传递；成功分支只完整重绘一次，去除不可达的常驻成功卡片代码。历史撤销以实际恢复结果更新轮次状态，恢复失败不会误标记成功；撤销期间禁用重复操作。
- 时间轴拆出路径内容与属性行控件渲染方法，去除嵌套长条件表达式；继续复用原时间轴命令和区间拖拽。
- 构图边距、邻近道具范围、单人/多人占比集中为只读参数。投影计算复用临时向量，拒绝空/非有限边界与非法投影参数；零向量与正上/正下方观察使用稳定基向量，避免退化计算。
- 公共角色创建入口明确分离角色计数、默认颜色与显式覆盖；生成场景切视角逻辑展开为可审查步骤，清除无效注释与尾部空白。

验证日志：`test-output/quality/check.log`、`build.log`、`regression.log`、`round3-final.log`。单元测试覆盖真实构图算法及其异常边界；真实 UI 验证覆盖草稿、继续对话、历史撤销失败/成功、轨道拖拽、旧文档、截图和视频导出。
