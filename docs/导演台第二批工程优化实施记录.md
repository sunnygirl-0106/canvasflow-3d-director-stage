## B2 模型与资源交付

两个素体采用 gltfpack 1.3.0 的 `-cc -ce ext -kn -km -ke -noq` 候选：male 984980 → 401256 字节，female 883400 → 365632 字节，合计减少 58.95%。不增加几何量化；EXT_meshopt_compression 已用当前 Three r160 加载验证。更小的 compact 候选也通过实验，但未选用，保留精度余量。

运行 `node scripts/model-candidates.mjs` 可从 Git 修订 `7717264` 提取原始 GLB 并复现两档候选，源/产物 SHA-256、参数和字节数均在[实验报告](references/optimization-b/b2-model-runtime.json)。随后运行 `CHROME_PATH=... node scripts/check-model-candidates.mjs`：3 个基础档案、4 个派生体型，所有姿势预设及 8 个步态采样、正面/斜视双画面，检查骨骼映射、皮肤权重、逆绑定矩阵、骨骼包围盒与脚底采样。13 组对照全部通过。不量化候选最大脚底误差约 3.5e-9 m，像素差异最大 0.00174%，来自重新排列顶点后的浮点渲染微差。加载耗时仅作同进程观测，受缓存影响，不作为冷加载加速结论。
