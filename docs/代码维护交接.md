## 时间轴验收修复

用户再次要求「继续干活」后，继续处理剩余时间轴失败。先对未修改的套件重新运行，复现 25/27；随后仅修改 `e2e/suites/tl.mjs` 和本交接文档。

根因与修复：

- Esc 截图比较混用了播放前的导演视角和停止后的机位视角。现有 `docs/试用指南.md`、`App._preparePlayback` / `stopPreview` 及机位验收均约定播放进入机位、停止保留机位。本次新增停止状态断言（idle、时间归零、退出预览、机位保留），再通过界面切回导演视角比较；保留 0% 像素差要求，实测 `0.0000%`。
- 输入框暂停用例只创建了两个角色，没有播放所需的机位，实际在 t=0 被拒绝播放。为该播放用例补建机位，并检查点击前确实 playing、时间已推进，再检查暂停时刻写入第三个位置键且不自动续播。实测约 0.506 秒写键，值为 0.7。
- 轴标签用例原先只检查 paused，可能在没有开始播放时误通过。补查点击前 playing 和暂停时刻；现已验证真实的播放到暂停转换。
