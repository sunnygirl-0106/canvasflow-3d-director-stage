## 1. 背景

角色能走了，机位还只能手动摆或者打键。阶段 F 让机位"会动"：7 种运镜一键生成、机位也能画路径、播放时从主机位看。对齐竞品 liblib：选中机位 → 选运镜 → 调参数 → 播放；多个运镜可以接着拼。

运镜预设 = `pathGen` 生成的机位路径 + 注视约束，这是阶段 C 就定的；本阶段只是把它们组合起来并给名字。预设名是 AI 词汇表的一部分，定了不改。

## 2. 要解决的问题

1. 7 种运镜各自的几何定义（相对谁、多远、多久），参数怎么给默认值、怎么改。
2. "追加拼接"：一个机位只能有一条路径，第二个运镜要接在第一个后面而不是替换。
3. 机位路径的绘制平面（机位有高度，不在地面）和入口。
4. 主机位播放：播放时主视口透过 `mainCameraId`；没设主机位时怎么办。
5. 运镜期间机位的手动朝向 / 关键帧 / 约束之间的优先级（沿用 4.3 的顺序，不新发明）。

## 3. 目标架构

### 3.1 运镜词汇表（`src/anim/cameraMoves.js`，纯函数：输入机位当前位姿 + 主体 + 参数 → `{ points, lookAt, duration }`）

| 名字 | 含义 | 几何 | 参数（默认） |
|---|---|---|---|
| `push_in` | 推 | 沿机位→主体连线向主体直线靠近 | `amount` 靠近距离（当前距离的 40%）|
| `pull_out` | 拉 | 同上反向远离 | `amount`（当前距离的 60%）|
| `truck` | 横移 | 垂直于连线、水平方向平移，保持注视主体 | `amount` 2 m，`dir` left/right |
| `crane` | 升降 | 垂直方向平移，保持注视主体 | `amount` 1 m，`dir` up/down |
| `pan` | 摇 | 机位**不动**，只转朝向：从当前朝向水平摇到看向主体（主体是点或实体） | 无路径；生成 rot 关键帧 2 个（起 = 当前，止 = lookAt 主体后的朝向）|
| `half_orbit` | 半环绕 | 以主体为圆心、当前距离为半径、当前高度，水平扫 180° | `sweep` 180，`dir` cw/ccw |
| `circle` | 环绕 | 同上扫 360°，`closed=true` | `sweep` 360，`dir` |

- 所有带路径的预设：路径点 y = 机位当前高度（`crane` 除外），`speed='smooth'`，`orient='keep'`（机位朝向由 lookAt 决定，不用切线），并自动加 `lookAt` 约束指向主体（`pan` 也加，start=结束时刻，让它摇到之后保持盯着）。
- `duration` 默认：`push_in / pull_out / truck / crane` 3 s，`pan` 2 s，`half_orbit` 5 s，`circle` 8 s。`start = playback.time`。
- 主体 `subject`：默认 = 场景里离机位最近的角色；可在 Inspector 改成任意实体或自定义点。没有任何实体时 subject = 机位前方 3 m 的点。
- 预设参数**不进文档**（同 E 的 arc），文档只存生成的 points / keys / constraints；参数存会话态 `app.moveMeta[cameraId]`，重载后退化为普通路径（已知问题里已有同类条目）。

### 3.2 追加拼接

机位已有路径时，「应用」按钮变成「追加」：
- 新运镜的起点 = 现有路径的终点（位置）和 `start + duration`（时间）；新 points 去掉首点后接到现有 points 后面；`duration` 累加；`closed` 置 false（circle 追加后不再闭合）。
- 新的 lookAt 约束 `start/end` = 该段的时间窗；上一段的 lookAt `end` 设为该段 `start`。同一主体连续两段合并为一条约束。
- 拼接后仍是一条路径、一条 `smooth` 速度曲线：段与段之间不停顿（写进已知问题：要停顿得手动拆成两个机位或等以后做分段速度）。
- `pan` 不能追加在路径后（它不动位置）：toast 提示"摇镜头请单独使用或放在最前"。
- 「清除运镜」= 删路径 + 删该机位全部约束 + 删 rot 轨道（一次撤销）。

### 3.3 机位路径绘制

- `PathTool.canDraw` 放开机位：绘制平面 = 过机位当前位置的水平面；环绕的中心默认吸附到实体，半径取机位到中心的水平距离。
- 机位路径默认 `orient='keep'`（不要让机位沿切线转，那是车不是镜头）；Inspector 路径段的 orient 下拉对机位仍可改。
- 机位的路径 overlay 画在机位高度；机位视角下不显示（同 E）。
- 五种方式里的「走到」对机位叫「推到」（同一个 `toward`，stopDistance 默认 1.5 m）。

### 3.4 主机位播放

- transport 的「主机位」下拉已存 `mainCameraId`。新增行为：
  - 处于**机位视角**时，播放头 active（播放或拖动）→ 视口透过主机位；idle → 回到当前选中的机位（原有行为）。主机位未设 → 用当前机位，并在视口左上角灰字提示"未设主机位"。
  - 处于导演视角时不切换（导演想看全局）。
  - 透过主机位时 Inspector 仍可选中别的实体，但 gizmo 隐藏（画面是成片预览）。
- 「机位视角」按钮旁加一个小标签显示当前透过的机位名。
- 阶段 G 导出用的就是这条规则：每帧 = `evaluate(t)` 后用主机位 `snapshot`。

### 3.5 机位 Inspector 新增「运镜」段（在「约束」段之上）

```
运镜   [预设下拉: 推/拉/横移/升降/摇/半环绕/环绕]
主体   [下拉: 最近角色(默认) / 各实体 / 自定义点 xyz]
参数   amount / dir / sweep（按预设显示）    时长 [ ] s
[应用] 或 [追加]       [清除运镜]
已有运镜：段列表（名字 · 起止秒），每段可删（删除 = 从 points 里切掉该段并修约束，一次撤销；只允许删最后一段，中间段提示"请清除后重做"）
```
- 改参数 → 实时重算**预览**（overlay 用虚线画将要生成的路径），点「应用/追加」才写入。
- 「约束」段保持阶段 D 的样子；运镜生成的 lookAt 在那里也能看到和改。

## 5. 验收标准（selftest `cam` 子命令，截图到 `test-output/cam/`）

1. **单元**：7 种预设各 ≥ 2 个断言；`appendMove` 接续点重合、duration 相加、约束窗口不重叠。
2. **半环绕盯人**：机位对角色A应用 `half_orbit`（5 s）：每 0.25 s 采样，机位到角色的水平距离恒定 ± 1 cm，机位高度恒定 ± 1 mm，角色注视点投影到画面中心的偏差 < 2% 画幅；t=0 与应用前截图 0%（不跳）。
3. **推 / 拉**：`push_in` 终点到主体距离 = 原距离 × 0.6 ± 1 cm；`pull_out` = × 1.6。
4. **横移 / 升降**：`truck` 终点位移垂直于初始连线（夹角 90° ± 1°）且 y 不变；`crane` 只有 y 变化 1 m。
5. **摇**：`pan` 不产生路径，产生 rot 轨道 2 键；t=duration 时机位 −Z 指向主体（< 0.5°）；位置全程不变。
6. **追加**：`push_in` 后追加 `half_orbit`：一条路径、points 连续（接缝处两点重合）、duration = 3+5、两条 lookAt 时间窗 [0,3] / [3,8]（同主体则合并为一条 [0,8]）；播放 t=3 处机位位置连续（t=2.99 与 t=3.01 距离 < 2 cm）。
7. **删末段**：删除后 points / duration / 约束回到追加前，⌘Z 恢复。
8. **机位画路径**：对机位用「点击落点」画 3 点：所有点 y = 机位高度 ± 1 mm；overlay 在机位高度；机位视角下不显示。
9. **主机位播放**：设主机位为机位2，切到机位视角选中机位1，按 Space：视口截图 ≡ `stage.snapshot(机位2.cam)` 同一 t 的像素（< 0.5%）；Esc 后视口回到机位1（0%）。未设主机位时显示提示文案。
10. **往返**：含运镜（追加过）的文档 导出 → 导入 → 导出 ≡；导入后 `seek(4)` 截图 ≡ 导入前。
11. 所有回归（e2e / doc / anim / tl / path / collide）+ lint 全过。
12. 产品侧手动验收截图：7 种运镜各一张（t = duration/2）、追加后的段列表、虚线预览、主机位播放中、第 0 节修正后的面板。
