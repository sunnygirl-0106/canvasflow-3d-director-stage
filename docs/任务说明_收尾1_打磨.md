## 1. 要修的（按优先级，1–5 必做，6–8 尽力）

### 1. 名牌重叠避让
- 现象：两个角色在画面里前后站成一线时名牌叠在一起（导出 `sample.mp4` 尾帧可见）。
- 做法：每帧把所有可见名牌按屏幕 x 排序，矩形相交的往上推（后面的、离相机远的让位），推开距离 = 重叠高度 + 4 px；DOM 名牌和精灵名牌用**同一个**布局函数，保证视口 / 截图 / 导出一致。
- 验收：构造两人前后站位的场景，截图里两个名牌矩形不相交；没有重叠时位置与现在逐像素相同。

### 2. 路径开始时的瞬间转身 → 平滑转过去
- 现象：`orient=tangent` 的路径在 t=start 那一刻角色突然转向首段方向。
- 做法：在 `PathTrack` 里，朝向 = 从"手动朝向（base yaw）"到"切线 yaw"的插值，插值进度 = 已走路程 ÷ 0.6 m（clamp 0..1），走完 0.6 m 就完全跟切线。纯函数、按路程不按时间，不破坏 `evaluate(t)` 的纯度。`speed=smooth` 时起步慢，转身自然就慢。
- 验收：t=start 朝向 ≡ 手动朝向（< 0.5°）；走 0.6 m 后朝向 ≡ 切线（< 0.5°）；中间每帧 yaw 变化 < 15°/帧（30 fps）；anim / path 回归全过。

### 3. 运镜开始时镜头瞬间甩过去 → 平滑对准
- 现象：机位原本没对准主体时，lookAt 约束从 start 那一刻生效，镜头一下甩过去。
- 做法：`Constraint.lookAt` 增加入场混合：在 `[start, start+0.5 s]` 内把"约束前的朝向"和"注视朝向"做四元数 slerp（start 为 null 时视为 0，且 t=0 之前无"约束前朝向"，直接全量生效——即只对 start>0 的 lookAt 做混合）。同样的 0.5 s 混合用于 `end`（退出）。
- 验收：start=2 的 lookAt，t=2.0 朝向 ≡ 约束前，t=2.5 朝向 ≡ 注视，中间单调；cam 回归全过。

### 4. 运镜拼接处 / 角色路径中途可停顿：路径可选 `stops`
- 现象：推 3 s + 半环绕 5 s 拼在一起后成一条缓入缓出曲线，两段之间不停、各段时长只是名义。
- 做法：路径文档**新增可选字段** `stops: [顶点索引, ...]`（升序、不含首尾、缺省为空；校验器接受缺省，旧文档不受影响，schema 版本不升）。有 stops 时速度曲线按段分别缓入缓出，各段时长按弧长比例分配；`appendMove` 自动在接缝处加一个 stop，并把各段时长**按名义时长**分配（推 3 s 就是 3 s）。Inspector 路径段给「在选中顶点处停顿」勾选；AI 的 `set_path` 允许 `stops`；运镜段列表显示的起止时刻从此是真的。
- 验收：推 3 s + 半环绕 5 s：t=3.0 机位速度 < 0.05 m/s，t=0..3 内机位始终在推的那条线段上（偏离 < 2 cm），总时长 8 s；无 stops 的旧文档往返 ≡；doc / anim / cam 回归全过。

### 5. 时间轴面板列出所有实体
- 现象：没有动画数据的实体不在面板里，用户找不到"怎么给它打键"。
- 做法：所有实体都列一行（折叠态，只有表头），没动画的灰字 + 右侧一个「◇ 打键」快捷按钮（= Inspector 的位置菱形）；有动画的照旧展开。
- 验收：新建场景两个角色即出现在面板；点快捷按钮后出现 pos 行且 t=0 有键。

### 6. AI 抽屉打开时自动取景避开抽屉
- 做法：`frameSubjects` 取景时把抽屉宽度从可用视口里扣掉（抽屉关了恢复）。
- 验收：抽屉开着生成场景，所有角色包围盒投影落在抽屉左侧区域内。

### 7. 急转弯打滑（尽力，不强求）
- 做法：Locomotion 的朝向用"前后各 0.25 m 的切线平均"代替瞬时切线，让转弯更圆；超过 60° 的折角仍会滑，接受。
- 验收：直线路径 ≡ 现在（逐数值）；90° 折角路径上支撑脚在地面的水平滑动量比现在减少 ≥ 30%（报告里给前后数字）。做不到就回退并说明。

### 8. 播放中在 Inspector 输入框改被驱动属性被覆盖
- 做法：和 gizmo 一样，输入框聚焦时暂停播放，失焦 / 回车后不自动恢复。
- 验收：播放中点进位置输入框 → state 变 paused；改完回车 → 键已写入。
