# 任务说明 · 阶段 D · 时间轴面板 + 属性面板联动

> 读者：Claude Code 执行者。先读《交接文档_导演台重构.md》第 4.3、6 节和 README「动画 API」，再读本文。
> 分支：阶段 C 合入主线后从主线开 `feat/timeline-ui`。
> 本阶段**只做界面**，不改 `src/anim/` 的求值语义；唯一允许动的内核接口是 3.3 里的"active 期间编辑 → 打关键帧"。

## 1. 背景

阶段 C 的动画内核只能在控制台里用。阶段 D 给它一个面板：看得到轨道和关键帧、能拖播放头、能在属性面板上一键打键、能播放。做完之后，产品侧第一次能不写代码地做出一段"角色走过去、机位推近"的动画，阶段 E（路径绘制）和 F（运镜预设）都在这个面板上长出来。

参考：liblib.tv 导演台的时间轴（底部、按实体分组、菱形关键帧、路径显示为起止两颗菱形）。

## 2. 要解决的问题

1. 底部时间轴面板：标尺、播放头、按实体分组的轨道行、关键帧菱形、路径/约束的区间条。
2. 播放控制：播放/暂停/停止、循环、时长、fps、吸附。
3. 属性面板联动：每个可动画属性旁一颗菱形，一键打键/删键；当前时刻有键时实心。
4. **active 状态下编辑的归属**（阶段 C 留下的口子）：拖 gizmo 或改面板时，到底是改手动值还是打关键帧。
5. 路径和约束的参数（start/duration/speed/orient、subject/offset/start/end）要有地方改；路径的**绘制和顶点拖动留给阶段 E**，本阶段只能改参数、不能画。
6. 选中联动：面板上点轨道行 = 选中实体；选中实体 = 高亮其轨道。

## 3. 目标架构

### 3.1 布局

```
#app（column）
├─ header（不变）
├─ main（不变：Outliner | 视口（Dock 悬浮） | Inspector）
└─ #timeline（新增，默认展开高 220px，可折叠到只剩 36px 的播放条）
     ├─ .tl-transport   ⏮ ◀ ▶/⏸ ▶| ⏭ ｜ 00:02.47 / 00:10.00 ｜ 循环 ｜ 吸附 ｜ fps[24/25/30/60] ｜ 时长[__]s ｜ 主机位[下拉] ｜ 折叠
     ├─ .tl-left        实体分组表头（可折叠）+ 轨道行名（pos/rot/scale/fov/路径/注视/跟随）
     └─ .tl-right       标尺（秒 + 帧刻度，随缩放变密）、播放头（红线 + 顶部三角，可拖）、各行关键帧/区间条；横向滚动 + ⌘滚轮缩放
```
- Dock 新增「时间轴」按钮切换展开/折叠；折叠状态记 localStorage（会话偏好，不进文档）。
- 视觉沿用 `style.css` 的变量（`--panel/--line/--accent/--dim`）；关键帧菱形 10px，选中用 `--accent`，路径区间条用 `--green` 30% 填充 + 起止两颗菱形，约束区间条用紫色系；active 时播放头红线延伸到视口底边不需要，只在面板内。
- 新文件：`src/ui/timeline/{TimelinePanel,Transport,Ruler,TrackRows,keyDrag}.js` + `src/styles/timeline.css`。不改 `Dock/Inspector` 的现有布局，只加元素。

### 3.2 面板行为

- **播放头**：拖动 = `playback.seek(t)`（吸附开启时 `snap`）；点击标尺跳转；`Space` 播放/暂停、`←/→` 前后一帧、`⇧←/→` 前后一秒、`Home/End` 首尾；`Esc` = `stop()`（回手动值）。输入框聚焦时快捷键不触发。
- **关键帧**：单击选中（⇧多选），拖动改 t（松手才记撤销、吸附生效），`Del` 删除，双击弹 ease 选择（linear/smooth/step），`⌥拖` 复制。拖过另一键的 t 时合并（覆盖）。
- **路径区间条**：拖中间改 `start`，拖右端改 `duration`；双击打开 Inspector 路径段。
- **约束区间条**：start/end 为 null 时铺满全程并显示"全程"；拖两端设 start/end。
- **行**：实体表头行显示名字 + 类型图标 + "删除全部动画"；轨道行右键菜单：删除轨道、清空键。空轨道显示为灰色虚线行。有路径的实体不显示 pos 行（互斥，校验器会拒）。
- 面板只在 `timeline` 'change' 时重建行；播放头在 'tick' 时只改 transform，不重绘；`playback` 'state' 切换播放按钮图标。
- 'active' 为真时，Inspector 顶部显示一条细提示"时间轴激活中：修改会写入当前时刻的关键帧"；`stop()` 后消失。

### 3.3 active 期间编辑的归属（本阶段的核心决定，按此实现）

把 `App.edited(ent)` 的语义改成：
- 时间轴 **idle**：和现在一样，改手动值。
- 时间轴 **active**：对该实体每个被修改的属性（pos/rot/scale/fov，由调用方传入 `props` 集合；gizmo 按当前模式传一个，面板按改的字段传）：
  - 该属性**有轨道** → `timeline.setKey(track.id, playback.time, 当前值)`（有键则覆盖，ease 沿用被覆盖键的或 linear）。
  - 该属性**无轨道**，且「自动打键」开 → `addTrack` + `setKey`（一次撤销）。
  - 该属性无轨道，且自动打键关 → `refreshBase`（改手动值，现有行为）。
  - 该属性被**路径或 follow 驱动** → 不记、toast 提示"该属性由路径/跟随驱动"。
- 「自动打键」是 transport 上的一个开关（红点图标），默认关，会话偏好存 localStorage。
- `setKey` 用的值口径 = 文档口径（角色 pos 相对站立基准、rot 欧拉角度数），复用阶段 B 的 `_docTransformOpts`，不要另写一套换算。
- 这一条要补进交接文档 4.3，并把"阶段 D 改成打关键帧"那句删掉。

### 3.4 Inspector 联动

- 位置 / 旋转 / 缩放 三栏，以及机位的 FOV 栏，标题右侧各加一颗菱形按钮：
  - 无轨道：空心灰；有轨道但当前时刻无键：空心亮；当前时刻有键：实心 accent。
  - 点击：无键 → 打键（无轨道先建）；有键 → 删键（轨道空了保留，不自动删）。
  - 时间轴 idle 时点击 = 在 t=0 打键并 `seek(0)`（进入 active），这是"第一次打键"的入口。
- 角色 / 道具 / 组 的 Inspector 新增「路径」段（有路径时显示）：start、duration、speed、orient、closed、点数（只读）、删除路径。本阶段没有"新建路径"按钮——控制台或阶段 E。
- 机位 Inspector 新增「约束」段：注视（subject 下拉：无 / 各实体 / 自定义点 xyz）、跟随（subject 下拉 + offset xyz）、各自 start/end；改动走 `addConstraint/updateConstraint/removeConstraint`。
- Inspector 上的数值在 'tick' 时跟着刷新（被驱动的属性显示求值结果，灰字；手动属性正常）；刷新节流到每帧一次。

### 3.5 其它

- `mainCameraId` 下拉只存值（阶段 F 才用它切视角）。
- 删除实体、打组/解组的连带删除（阶段 C 已做）面板只需响应 'change'。
- 导入文档 / 撤销 / 重做后面板全量重建，播放头按 `playback.time` 夹到新时长内。
- 面板尺寸：窗口 < 900px 高时默认折叠。

## 4. 分步执行（每步一个 commit，报告改动文件、测试结果、截图路径）

1. **面板骨架 + transport + 标尺 + 播放头**：能展开/折叠、播放/暂停/停止/循环、拖播放头、快捷键、时长/fps/吸附、主机位下拉。此时轨道区为空。
2. **轨道行 + 关键帧显示**：按实体分组渲染轨道/路径/约束；选中联动；点击关键帧选中；控制台加的键能立刻显示。
3. **关键帧编辑**：拖动、多选、删除、ease、⌥复制；路径/约束区间条拖动；右键菜单。全部经 timeline API，撤销粒度 = 一次松手。
4. **Inspector 菱形 + 3.3 的编辑归属 + 自动打键开关**：改 `App.edited(ent, props)`；gizmo 松手 / 面板 change 时按 3.3 处理；Inspector 数值随 tick 刷新。
5. **Inspector 路径段 / 约束段**。
6. **验收 + 文档**：selftest `tl` 子命令（见第 5 节）；README 操作表加时间轴快捷键；交接文档 3 阶段表、4.3（3.3 的决定）、5 代码地图、6 下一步（阶段 E）；本文件移到 `docs/done/`。

## 5. 验收标准（selftest `tl` 子命令，puppeteer 真实点击/拖拽，截图到 `test-output/tl/`）

1. **从零做一段动画只靠界面**：添加角色 → 选中 → 点位置栏菱形（t=0 打键）→ 拖播放头到 3s → 用 gizmo 把角色拖到 (2,0,1)（自动打键关、但已有轨道 → 写键）→ 播放头回 1.5s → 截图；预期角色位于两键中点 ±1 cm。
2. **自动打键**：开自动打键，t=2 时拖一个没有轨道的道具 → 产生 pos 轨道 + 1 键；关自动打键重复 → 道具 base 改变、无新轨道。
3. **菱形状态**：t=0 实心、t=1.5 空心亮、无轨道实体空心灰（截图比对 Inspector 区域）。
4. **拖键**：把 3s 的键拖到 4s（吸附开，fps 30）→ `timeline.toJSON()` 里该键 t=4.0；撤销一次回 3；重做回 4。
5. **区间条**：控制台加一条路径（start 0, duration 4），拖右端到 6s → `duration=6`；拖中间到 start 1 → `start=1`；Inspector 路径段显示一致。
6. **约束段**：机位 Inspector 选"注视 → 角色A"→ 文档出现 lookAt；改 start=1,end=3 → 文档一致；选"无"→ 删除。
7. **播放**：`Space` 开始，1 s 后截图，与 `seek(≈1.0)` 的截图像素差 < 0.5%（真实播放有帧时间抖动，允许用 `playback.time` 回读后再 seek 比对）；`Esc` 后场景 ≡ 进入前截图（0%）。
8. **快捷键**：`→` 一帧 = 1/fps；`End` = duration；输入框聚焦时 `Space` 不触发播放。
9. **折叠**：折叠后视口高度增加 184px，刷新页面保持折叠。
10. **面板性能**：100 个键、10 条轨道时播放 5 s，主线程长任务（>50 ms）为 0（用 PerformanceObserver 记录）。
11. 原有 e2e、doc、anim、collide 全过；lint 过。
12. 产品侧手动验收清单（写进报告，附截图）：面板展开图、一次打键后的 Inspector、拖键中、播放中、路径区间条、约束段。

## 6. 约束

- 不引入新依赖，不用框架；DOM 操作沿用 `util/dom.js` 和 `ui/widgets.js` 的方式。
- `src/anim/` 只允许改 `Timeline.refreshBase` 相关的入口（或新增 `Timeline.editAt(ent, props, t)` 封装 3.3 的分支）；求值顺序、插值、步态、约束一律不动。改了 `src/anim/` 的任何文件必须跑 `selftest anim`。
- 所有写操作走 timeline API，面板自己不持有文档状态；面板不能出现"显示的和 `toJSON()` 不一致"的时刻。
- 关键帧值口径复用阶段 B 的换算（`_docTransformOpts`），禁止在 UI 层再写一份。
- 词汇表不变；新增 UI 文案用中文，和现有面板一致。
- 不做：路径绘制与顶点拖动（阶段 E）、运镜预设（F）、播放时切主机位（F）、曲线编辑器、姿态关键帧（铁律）。
- 说明没覆盖的决策：停下来列选项问。预计会碰到的：旋转键在面板上怎么显示（建议只显示菱形，不显示数值）；多选键整体拖动是否吸附每一颗（建议按首颗吸附、其余保持相对间距）。
