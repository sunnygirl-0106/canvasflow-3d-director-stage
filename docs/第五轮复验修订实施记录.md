# 第五轮复验修订实施记录

日期：2026-10-23。实施依据：[复验与机位轨迹修订](导演台第五轮复验与机位轨迹修订.md)。本记录替代此前验收记录中关于独立默认构图、初始操作手柄和UI绘制步速估算的结论。

## 已实施的三项补修

1. **统一构图。** 新场景两视角共用位置 `[0,2.2,10]`、注视 `[0,-0.71,0]`、FOV 50°，不再附加人物上移5%的偏置。人物世界位置保留。未主动操作观察相机时，默认主机位的位置、朝向和FOV变化同步到导演相机；真实OrbitControls手势发生变化后脱离同步，视角切换不触发脱离。重置读取默认主机位当前构图并恢复同步。
2. **首屏无操作Gizmo。** `transformEditing` 区分默认属性选择与明确变换操作，显隐和拾取共用判断。首屏角色A属性仍可见，方向导航保留；默认机位机身、标签和近/远端框不显示，只保留视锥侧线几何。明确选择或点击变换工具后恢复手柄，取消选择、播放和洁净渲染期间禁用；载入/撤销保留该会话状态。
3. **UI新绘制和重绘均为0～10秒。** 在 `PathTool._commit()` 统一提交实际时长，覆盖五种绘制及走到/推到的公共流程。总场景不足10秒时在同一事务延长；30秒场景仍只创建10秒路径。插点、移动节点、旧5.1秒路径载入及显式6秒设置保持各自数据。`defaultDuration()` 继续服务按步速调整和非UI业务，迈步频率保留1.32周期/秒。

`meta.editorView.fov` 是当前schema中的可选字段，新增有限范围校验；导出保存真实FOV，旧文件缺失时恢复40°。没有提升schema版本或要求旧文件补字段。CameraRig的home同时保存和恢复位置、target及FOV，重置会先清空旧阻尼增量。同步关系为会话状态，不增加相机实体；载入时仅识别一次保存视角与主机位是否一致，不逐帧比较浮点变化猜测用户意图。

主要入口：`core/framing.js`、`app/defaultScene.js`、`app/App.js`、`core/CameraRig.js`、`app/DocumentController.js`、`doc/schema.js`、`entities/Camera.js`、`app/Labels.js`、`app/PathTool.js`、`main.js`，均位于 `src/`。
