# 角色轨迹显示与三维关键点编辑实施记录

2026-10-23。保留开始时工作区已有修改；未改 schema、动画插值算法、路径时间模型和已确认默认参数。功能实现及专项验收已落地，完整回归仍有一项既有导出名牌断言未通过，不能将本文视为全部验收无遗留。

## 实现与边界

- `PathOverlay.js`：补位置键轨迹，复用 Channel；step 不连伪造线，单键只画点，空轨道不画点。当前来源/节点只有一份会话状态，旧接口派生读取。局部预览复用几何与材质，播放只移动亮点。跟随覆盖位置时隐藏误导轨迹并拒绝编辑。
- `PathEditor.js`、`TransformGizmo.js`、`App.js`：一个点代理复用原 Gizmo，世界 XYZ 平移；保留直接水平拖点及 Shift 整条平移。完整父矩阵转换，不写模型站立偏移或绘制 LIFT。拖动事务保存版本与来源快照；Esc、pointercancel、失焦、删除、换角色、导入及版本冲突取消预览。渲染前刷新候选，避免一帧内角色与线不同步。
- `Timeline.js`、`Playback.js`：显式单来源候选透传，沿原关键帧→路径→步态→约束顺序求值，复用运行时模型缓存。预览不写文档；松手通过现有 API 提交一次，零位移不提交。
- `TimelinePanel.js`、`TrackRows.js`、`keyDrag.js`、`timeline.css`：双向定位、高亮、滚动；不强开折叠面板、不改变观察机位；保留多选和拖键时间语义。复制、覆盖后绑定存活键，闭合回归点保留末次到达信息。
- `SceneFile.js`、`VideoExporter.js`：自动保存延后到拖动结束；主动保存、截图、视频和载入先取消候选。修复了自动保存定时器打断连续拖动的问题。
- 测试：扩展 `timeline.test.mjs`、更新 `pathselect` 焦点断言，新增 `motion` 浏览器套件及 `e2e/tools/motion-performance.mjs`。

## 根因与复现

原 Overlay 只读取 paths，未读取 pos 轨道，因此位置关键帧运动没有轨迹；原拖点只预览线，不求值角色；点拖动仅支持固定 Y 平面。已在隔离页面通过左栏、角色本体、轨迹线、节点和时间轴真实点击复现并验收，保留用户实际场景。没有取得用户原始问题场景，不能断言它只受以上原因影响；机位视角隐藏辅助物、无动画不画轨迹仍是预期行为。

可见性不只检查对象数量：路径开关截图差异 227 像素，位置键轨迹也有真实开关像素对比。详见 `test-output/motion/line-on.png`、`line-off.png`、`pos-line-on.png`、`pos-line-off.png`。

## 性能

同设备、1440×810、headless Chrome SwiftShader，100 节点曲线约 5 秒：

| 测量 | 修改前线预览 | 修改后线预览 | 修改后真实鼠标拖轴（含角色求值） |
| --- | --- | --- | --- |
| 更新 P50 / P95 | 2.3 / 2.9 ms | 1.9 / 2.4 ms | 约 2.1 / 2.4 ms |
| 完整帧 P95 | 224.9 ms | 88.3 ms | 100.1 ms |
| 预览提交 | 0 | 0 | 0，松手 1 次 |

软件渲染仍有大量 >50ms 长帧，这些数据不代表硬件 GPU 帧率。12 次进入/退出编辑，资源稳定在 29 geometries / 4 textures；播放保留同一个路径模型。原始分布与长帧计数：`test-output/motion/baseline.json`、`performance.json`。可用 `node e2e/tools/motion-performance.mjs` 重测。
