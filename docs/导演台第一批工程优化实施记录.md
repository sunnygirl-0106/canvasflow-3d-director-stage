### A2 异步保存与恢复

- `AutosaveRepository.js`：IndexedDB 快照 + 元数据事务，事务完成才成功；每页面独立会话，一份最新完整场景 JSON。存储版本与场景 schema 分离，未改 JSON/dataURL 格式。
- `SceneFile.js`：提交历史后 1 秒防抖、串行写入、写入中合并到最新版本；记录/撤销/重做/导入均覆盖，启动 reset 不写，拖动与文档加载期间延后。
- `SaveStatus.js`：持续显示未保存/保存中/已保存/失败；展开提供导出、重试、恢复和删除恢复点。异步读取不自动替换场景，恢复走原子加载，可撤销；恢复前先保存当前编辑，恢复后新快照落盘才处理来源恢复点。
- 两标签页互不覆盖；删除比较用户所见序号和时间，避免删掉对方更新。最多 20 个会话，满额明确提示，不自动清除未处理候选。
- 旧 localStorage 内容先 JSON/migrate/validate，再原子写快照及迁移标记。保留旧键，不再双写；损坏记录不阻断启动。隐藏页面时尽力保存，不把关页异步写入当完成保证。
- 浏览器验证约 9.6 MB、有效 2048×1024 PNG 全景的保存与刷新恢复，配额错误、真实事务 abort、手动下载、重试、双标签页、迁移一次、损坏记录、满额与禁用存储。[15 项真实浏览器验收](references/optimization/autosave.txt)、[恢复面板](references/optimization/recovery.png)。

### A3 导出取消边界

- 提取 `VideoEncoding.js` 管理编码器生命周期；背压/flush 可响应取消，主动 close，终止后禁止输出，所有 flush 拒绝均有处理，清理只发生一次。
- 将 flush 与封装留在同一导出会话内，最后一帧后不提前恢复渲染状态。取消和报错恢复播放头、名牌、洁净渲染、主渲染及 UI，不下载文件、不改变文档或撤销栈。
- 真实 MP4、普通取消与确定性检查保留；补充可重复注入积压、flush 取消及编码器异步错误的单测和浏览器测试。导出 27/27 通过。
