## 实施结果

| 需求 | 已实现行为 |
| --- | --- |
| 默认名称 | 新场景角色A、角色B；复用命名序号继续添加C/D，保存恢复保留自定义名称。旧文件不批量改名。 |
| 功能图标 | 统一亮白和白色悬停态，增加角色、机位、全景、画幅、识图语义细节，调整主要按钮热区；全屏包含完整页面及弹层。 |
| 主机位与首屏 | 新默认机位位置 `[0,2.2,10]`、注视 `[0,1.2,0]`、FOV 50°。导演观察相机独立构图，人物世界位置不变，人物投影上移约4.9%。 |
| 角色运动轨迹页 | 固定六字段：时长、位置、旋转、缩放、统一缩放、绑定对象沿路径朝向。复用属性页变换字段；修改位置平移整条路径与实体基准；沿路径朝向开启时锁定Y，关闭时连续交接姿态。 |
| 行走 | 新角色/群众路径默认步速1.44 m/s，步态1.32周期/秒。道具/机位保留原默认步速，旧路径时长不重写。 |
| 时间轴开关 | 删除Transport重复按钮及其样式，保留底部唯一入口、面板拖动和对象展开箭头。 |
| 左侧导航 | 共用固定侧栏宿主，保留场景树实例；7种真实角色、群众/几何模型、15种机位卡片、全景上传/历史、7种画幅、识图导入复用现有动作与注册表。 |
| 动画编辑 | 无轨道也可展开属性并打首键；前一个/菱形/后一个常驻。普通属性增删关键帧；轨迹位置行插控制点，不创建pos轨道。父子连线、底色与当前子行提示区分层级。 |

原路径反向、闭合、按步速调整等移到路径菜单的“轨迹操作”；停顿仍从节点右键操作，删除与重绘能力保留。播放tick只刷新值与按钮状态，不整表重建。

路径插点保留采样Y及停顿索引，一次撤销恢复。曲线插点仍遵循原曲线编辑语义，插入后定位到新路径的实际节点时刻；并不承诺Catmull-Rom曲线及到达时刻完全不变。零长度、近重复点、闭合接缝和区间外操作均设有保护。

基线 `dca9c4c` 也在独立临时工作区运行过全量检查，有8个套件未通过，见 [基线原始日志](../test-output/round5/logs/baseline-all.log)。本轮测试调整原因包括：

- 基线实际默认场景没有预置路径，相关业务测试改为显式建立路径夹具；角色名称、默认构图、固定机位、侧栏布局和唯一时间轴开关按第五轮规格更新断言。
- 属性树变长后真实点击需先滚动到可见行；长距离绘制点不能落在侧栏或覆盖画布的时间轴区域。绘制测试调整观察相机，仍验证真实鼠标绘制、几何误差、撤销记录和播放终点。
- 角色匀速路径从首帧朝切线；原旧测试仍套用机位的0.8 m转身过渡，已按现有角色语义修正。节点停顿从旧Inspector按钮改为真实节点右键入口。
- 视锥亮度原单像素采样在基线也失败，改为对真实可见线段取样，保留原亮度阈值；未放宽有效几何误差或导出一致性要求。
- round3基线出现一次ready超时，本轮全量运行该套件27/27通过；响应式工具条的旧坐标断言与基线几何也不一致，按实际基线校正并保持2px阈值。

## 构图与动画实测

1440×900及1920×1080窗口，分别验证16:9与9:16输出、时间轴打开和收起。角色A脚底从画布高度0.661167变为0.612212，角色B从约0.660582变为0.611727；上移约4.90/4.89个百分点。身体高度占比A从0.205864变为0.207172，B从0.189991变为0.191194。各组合中开关时间轴的角色投影完全一致，文档位置仍为 `[-0.7,0,0]` 与 `[0.7,0,0]`。完整中心/头顶/脚底数据见 [构图标定](../test-output/round5/calibration.json) 和 [基线标定](../test-output/round5/before/calibration.json)。

主机位真实前向为 `[0,-0.0995037166,-0.9950371904]`，平行 `[0,-1,-10]`。本项目序列化欧拉角约 `[-5.710593°,0°,0°]`，由真实注视方向求得；没有照抄竞品180°角度。旧项目机位加载往返保持原参数。

四体型相同8 m路径的默认时长由6.7秒变为5.6秒，比值0.83582，接近目标1/1.2（差异来自0.1秒取整）。两边均通过相同时间重复求值一致性检查。对比使用同一机位、男性/女性/纤细/宽厚四种体型，直接导出8秒MP4；短路径、闭合、停顿及导出确定性还由单元与动画/导出套件覆盖。场景剩余时长不足时仍沿用原有裁切规则，不强行延长总时长。

## 明确的能力边界

任意角色模型上传、AI全景生成未纳入本轮，也未放置假可用按钮。角色使用仓库已有7种模型；全景提供实际上传、历史和移除。已实现范围不等于与参考产品的全部能力相同。
