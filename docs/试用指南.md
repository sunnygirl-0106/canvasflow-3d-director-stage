# 3D 导演台 · 试用指南

> 写给不写代码的试用者。照着第 2 节走一遍大约 10 分钟。
> 遇到任何不对劲，按第 6 节的格式记下来就行。

---

## 1. 怎么启动

1. 打开「终端」，进入项目目录 `demo/`（第一次用先运行一次 `npm install`，装依赖要一两分钟）。
2. 运行：

   ```bash
   npm run dev
   ```

   终端会打印一个地址，一般是 `http://localhost:5173/`。
3. 用 **Chrome**（或 Edge）打开这个地址。Safari / Firefox 也能打开，但「导出视频」用不了。
4. 第一次加载人偶模型要等几秒，看到场景里出现**一男一女两个绿色人偶**就是加载好了。
5. 用完在终端按 `Ctrl + C` 关掉。

> 如果打开时右下角提示「恢复上次场景」：点它会回到你上次关掉时的场景；不点就从新场景开始。

### 界面长什么样

- **左边**：场景清单（所有角色 / 道具 / 机位，点名字就是选中）。
- **中间**：3D 视口。空白处按住左键拖 = 转视角，滚轮 = 远近，右键拖 = 平移。
- **视口下方的一排图标按钮**（下文叫「工具栏」），从左到右：
  变换（移动 / 旋转 / 缩放）· **小人 = 添加角色 / 道具** · 全景图 · **摄像机 = 添加机位** · **曲线 = 路径** ｜ 画幅比例 · 截图 ｜ **文档 = 场景菜单（撤销 / 导入导出 / 导出视频）** · 时间轴开关 · 全屏 ｜ **✦ = AI**。
  鼠标停在按钮上会显示名字。
- **右边**：没选中东西时是「场景」设置（天空、地面、名牌开关）；选中后是这个对象的属性面板。
- **最下面**：时间轴（播放条 + 每个对象一行）。窗口比较矮时它默认收起，点工具栏的时间轴按钮展开。
- **顶部正中**：「导演视角 / 机位视角」切换。

## 2. 十分钟试用路线

每一步后面的「→」是你应该看到的结果。看到的不一样，就是一个可以报的问题。

### ① 加角色

场景里已经有两个人（角色A、角色B）。再加一个：点工具栏的**小人**按钮 →「男性素体」。

→ 场景中央出现一个新角色（角色C），左边清单和下面时间轴里都多了一行。
（新角色放在场景中心，可能离镜头很近、挡住画面：滚轮往后滚拉远，或者按住拖动它脚下的彩色箭头把它挪开。）

### ② 换姿势

在左边清单点「角色B」→ 右边属性面板顶部切到「**姿势**」→ 点「**招手**」。

→ 角色B 立刻举起右手挥手。下面的滑条可以微调每个关节（0° = 自然站立），「⟲ 复位姿势」回到站立。

### ③ 画一条路径

保持角色B 选中 → 点工具栏的**曲线**（路径）按钮 →「**直线**」→ 在视口里**地面上**点一下作为终点（离角色两三米的地方）。

→ 地上出现一条蓝线（起点就在角色脚下）；时间轴里角色B 下面多了一条绿色的「路径」条。属性面板切回「属性」页往下滚，能看到「路径」一段（顶点数、总长、开始 / 时长、速度、朝向）。
轨迹随观察距离呈现近粗远细、近亮远暗；远处细线仍可轻松点选。画错了按 `Esc` 取消；重新绘制直接开始，完成后才替换该对象原有路径，取消保留原内容，完成后可撤销。

### ④ 按空格看他走

先在视口空白处点一下（让键盘焦点不在输入框里），再按 **空格**。

→ 画面先进入当前机位视角，再推进播放头，角色B 沿路线迈步走到终点。播放期间锁定观察操作，拖动会提示「播放中已锁定机位视角，暂停后可自由查看」。再按空格暂停，或按 `Esc` 停止并回到 0 秒；之后可切回导演视角自由观察。没有机位时会提示「请先添加播放机位」并阻止播放。

> 想让他走到一半停一下：在蓝线上点一下插入一个顶点（顶点会被选中），属性面板路径段里勾「**在选中顶点处停顿**」。

### ⑤ 加机位，选「半环绕」

点工具栏的**摄像机**按钮 →「正面全景」。

→ 场景里出现一个摄像机模型（名牌是橙色的「机位1」），自动选中；右边是它的属性面板。

属性面板往下滚到「**运镜**」段，把「预设」选成「**半环绕 half_orbit**」（主体默认是离机位最近的角色，也可以改），视口里出现一条虚线预览 → 点蓝色的「**应用**」。

→ 虚线变成机位的路径；时间轴里机位下面多了「路径」和紫色的「注视」两条；段列表里显示「1. 半环绕 0.0–5.0 s」。
（想再接一段：换个预设点「追加」，比如先「推」再「半环绕」，两段之间机位会停一下再走。）

### ⑥ 切到机位视角播放

1. 在时间轴播放条上，「**主机位**」下拉选「机位1」（成片就从这个机位出画）。
2. 点顶部的「**机位视角**」。
3. 按 **空格**。

→ 画面变成机位里看到的样子，镜头绕着角色转半圈；顶部显示「播放中 · 机位1」。播放时不能切回导演视角；暂停或按 `Esc` 停止后，点「导演视角」回来。直接从导演视角开始播放也会自动进入当前机位；主机位设置用于视频导出。

### ⑦ 导出 5 秒视频（只有 Chrome / Edge）

工具栏**文档**按钮（场景菜单）→「**导出视频…**」。在弹窗里：

- 分辨率保持「1080p」；
- 「范围」选「**自定义**」，起止填 **0** 和 **5**；
- 「名牌 · 画进视频」保持勾选；
- 点「**开始导出**」。

→ 弹窗显示进度（帧 i / 150、预计剩余时间），界面暂时锁住；完成后浏览器自动下载一个 `未命名场景_1920x1080_30fps.mp4`。用播放器打开：5 秒，主机位视角，角色头顶有名字牌。中途按 `Esc` 或「取消」可以取消，不会出文件。

### ⑧ 导出 / 导入场景文件

1. 场景菜单 →「**导出场景**」→ 下载一个 `.json` 文件（整个场景：人、姿势、路径、运镜、时间轴都在里面）。
2. 随便改点什么（比如删掉一个角色：选中后按 `Del`）。
3. 场景菜单 →「**导入场景**」→ 选刚才那个 `.json`。

→ 场景完整回到导出时的样子（删掉的角色回来了），提示「已导入场景」。报问题时附的就是这个文件。

### ⑨ 撤销几步

按几次 **`⌘Z`**（Windows：`Ctrl+Z`），再按 **`⌘⇧Z`**（Windows：`Ctrl+Shift+Z` 或 `Ctrl+Y`）重做。场景菜单里也有「撤销 / 重做」。

→ 每按一次退一步（加角色、换姿势、画路径、应用运镜、导入都各算一步）；重做按原样回来。

## 3. AI 抽屉（可选：需要模型接口的 key）

点工具栏最右边的 **✦** 打开右侧 AI 抽屉。

### 配置

点抽屉右上角 **⚙**，填三项后点「测试连接」：

| 项 | 填什么 | 例子 |
| --- | --- | --- |
| Base URL | 任何 OpenAI 兼容接口的地址 | `https://api.openai.com/v1`、`https://api.deepseek.com/v1` |
| API Key | 你的密钥 | `sk-…`（只存在这台电脑的浏览器里，不进场景文件） |
| Model | 模型名 | `gpt-4o-mini`、`deepseek-chat`（识图要选支持图片的模型） |

**没有 key 就跳过这一节**：没配置时输入框会提示「还没配置模型接口」，点发送只会弹出设置，其它功能都不受影响。
（有的服务商不允许浏览器直接调用，「测试连接」会报跨域 / 网络错误 —— 那就换一个服务商，或者记下来报给我们。）

### 三句示例提示词

抽屉顶部有三种模式：生成新场景 / 修改当前场景 / 识图导入。

1. **生成新场景**：「两个人在广场对话，一个女的站着挥手，一个男的坐着，一个机位半环绕拍他们，5 秒」
   → 直接开始生成，成功后场景换成两个人 + 一个带运镜的机位，可撤销；取消或失败时保留原场景。直接走第 2 节 ⑦ 就能出片。
2. **修改当前场景**：「让男的站起来走到女的旁边，机位改成推」
   → 只改提到的东西，其它不动。
3. **识图导入**：附一张站位草图 +「照图里的站位摆，机位从正前方拍」
   → 按图摆人（都是站姿，位置是大概的）。

每一轮 AI 改动 = 一步撤销，不满意点这一轮下面的「撤销这一轮」或按 `⌘Z`。

## 4. 快捷键（摘自 README，以 README 为准）

**视口 / 通用**

| 操作 | 效果 |
| --- | --- |
| 空白处拖动 | 环绕视角 |
| 滚轮 | 缩放 |
| 拖动三色 gizmo | 按当前模式变换选中对象 |
| `V` / `R` / `S` | 切换 移动 / 旋转 / 缩放 |
| `Del` / `Backspace` | 删除选中对象 |
| `⌘Z` / `Ctrl+Z` | 撤销 |
| `⇧⌘Z` / `Ctrl+Shift+Z` / `Ctrl+Y` | 重做 |
| 底部工具坞「场景」 | 撤销 / 重做 / 导出场景（.json）/ 导入场景 |
| 底部工具坞 `＋` | 添加角色 / 几何道具 / 本地上传 |
| 底部工具坞「时间轴」/ 面板右端 ⌄ | 展开 / 折叠时间轴（记住选择；窗口高 < 900px 时默认折叠） |

**路径**

| 操作 | 效果 |
| --- | --- |
| 点击落点 | 逐次点击地面落点；`Enter` / 双击结束，`Backspace` 退一点 |
| 手绘 | 按住左键在地面上拖，松手结束（自动简化） |
| 直线 | 点一下终点 |
| 环绕 | 点一下中心（地面或对象），属性面板里改半径 / 起始角 / 扫过角度（≥ 360° 自动闭合） |
| 走到 | 点目标对象，停在 0.8 m 外；`⇧` + 点地面取任意点 |
| 绘制中 `⌥` + 拖动 / 右键拖 / 滚轮 | 环绕 / 平移 / 缩放视角（左键归绘制）；`Esc` 取消 |
| 拖顶点 / `⇧` 拖顶点 | 移动该顶点 / 整条路径平移（松手才写入，一次撤销；拖动中 `Esc` 回原位） |
| 点路径线 | 选中实体的路径：在该处插入顶点；其它实体的路径：选中该实体 |
| 点顶点 + `Del` | 删除顶点（至少保留 2 个）；优先级：选中关键帧 > 选中顶点 > 选中对象 |
| 点中间顶点 → 属性面板「在选中顶点处停顿」 | 走到这个顶点停一下再走（停顿处速度为 0，各段各自缓入缓出） |

**时间轴**（输入框聚焦时不触发）

| 操作 | 效果 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `←` / `→` | 前 / 后一帧 |
| `⇧←` / `⇧→` | 前 / 后一秒 |
| `Home` / `End` | 跳到开头 / 结尾 |
| `Esc` | 停止：回到 0 秒，场景恢复手动值 |
| 点击 / 拖动标尺或播放头 | 跳转（吸附开启时按帧取整） |
| `⌘` / `Ctrl` + 滚轮 | 缩放时间轴（以光标处为中心） |
| 属性面板标题旁 ◇ | 当前时刻打键 / 删键（空心灰 = 无轨道，空心亮 = 有轨道无键，实心 = 有键）；时间轴未激活时在 0 秒打键并进入时间轴 |
| 时间轴面板里没动画的对象行「◇ 打键」 | 同上，给位置打一个键（所有对象都列在面板里） |
| 播放中点进属性面板输入框 / 按住轴标签拖 | 自动暂停（同拖 gizmo），改完不自动继续播放 |
| 单击关键帧 / `⇧` 单击 | 选中 / 多选 |
| 拖动关键帧 | 改时刻（按拖的那颗吸附，其余保持间距；落到已有键上即覆盖）；`⌥` 拖 = 复制 |
| `Del` / `Backspace` | 删除选中的关键帧（没有选中键时删除选中对象） |
| 双击关键帧 | 选缓动：linear / smooth / step |
| 拖路径条中间 / 右端 | 改开始时间 / 时长；双击打开属性面板的路径段 |
| 拖约束条两端 | 设生效区间（属性面板里清空 = 全程） |
| 右键轨道行 | 删除轨道 / 清空键 |
| 播放条 ● 自动打键 | 开：时间轴激活时修改没有轨道的属性也新建轨道并打键；关：只给已有轨道写键，其余算改手动值 |

## 5. 遇到问题怎么报

每个问题一条，按这个格式写：

```
【做了什么】一步一步写：点了哪个按钮、选了哪个选项、输入了什么
【看到什么】实际发生了什么（报错文字原样抄下来）
【期望什么】你觉得应该是什么样
【附件】截图（或录屏）+ 导出的场景 .json（场景菜单 →「导出场景」）
```

- 能复现的话写「每次都这样」，偶尔出现写「试了 5 次出现 2 次」。
- 导出视频的问题，把下载的 mp4 也附上。
- AI 的问题，把抽屉里那一轮的输入、展开的错误信息截图（不要截 API Key）。
- 浏览器和系统版本写一下（Chrome 版本在 地址栏输入 `chrome://version` 看）。

### 自救

| 情况 | 怎么办 |
| --- | --- |
| 改坏了 | `⌘Z` 撤销（最多 100 步），`⌘⇧Z` 重做 |
| 播放停不下来 / 角色不在原位 | 按 `Esc`（停止并回到手动摆的位置） |
| 视角转丢了 | 视口右上角坐标球下的「重置视角」 |
| 一直在画路径 / 点什么都没反应 | 按 `Esc` 退出绘制 |
| 页面卡住 / 白屏 | 刷新页面，右下角点「恢复上次场景」（每次改动 1 秒后自动存到浏览器里） |
| 想留一份 | 场景菜单 →「导出场景」存 .json，之后「导入场景」随时回来 |

## 6. 已知的限制（知道就行，不用报）

1. **导出视频只能用 Chrome / Edge**。其它浏览器里「导出视频…」是灰的。1440p 是实验选项，集成显卡上可能失败（会提示报错）。
2. **人偶是关节手办**：髋、肩扭得很大时关节处会露缝；手指不能单独调。高大 / 矮小 / 宽厚 / 纤细体型现在是男性素体拉伸出来的。
3. **急转弯时脚会滑一点**：沿直线走不打滑，转大弯（比如 90° 拐角）时站着的那只脚会在地上蹭一点；跑步时没有双脚离地的瞬间。
4. **运镜和环绕路径的参数刷新后就没了**：段列表、半径 / 扫过角度这些编辑框只在当前页面里有效；刷新页面或拖过顶点后变成普通路径（路径本身还在，还能「追加」）。
5. **手绘路径从别处开始画**时，开头会有一段从角色脚下连过去的线（路径总是从角色当前位置出发）。
6. **环绕的圆心不跟着人走**：主体在走路时套半环绕，圆心按点「应用」那一刻主体的位置算；镜头对准倒是实时跟着的。
7. **AI 还没有用真实模型试过**：自动测试都是模拟的，真实模型对朝向、坐标的理解可能有偏差；有的服务商不允许浏览器直连（跨域）。识图出来的站位是大概的，机位只猜方向。
8. **导出时视口里看到的不是成片**：导出过程中视口照常显示导演视角，成片只看下载的 mp4。
