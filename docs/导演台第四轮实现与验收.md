# 第四轮实现与验收

实施日期：2026-10-22。依据《导演台第四轮首屏与轨迹交互优化技术方案》，在 `main` 上实现；未改动用户交接方案及第三轮文档的既有修改。

## 场景核对与补建

本工作目录原默认场景仅有男角色和一个机位，没有 paths。本机既有 5173、5273 服务的工作目录均为其他项目，未发现可复用的运行中双人默认版本。因此本轮采用方案明确的 fallback，**双人与轨迹为补建，不声称保留了未找到的原设计**：

- 男角色 `[-0.7, 0, 0]`、女角色 `[0.7, 0, 0]`；各向局部 -Z 移动 0.8m，两条不交叉直线，时长 10s，30fps。
- 一个主机位，不添加相机运镜。新鲜启动不播放，只选中男角色；空文档、导入和恢复流程不补人。
- `defaultScene` 仍使用离场测量、文档原子发布和单一历史起点。场景树只在 UI 排序，将机位置于角色之前。
- 导演初始构图单独使用 `fitBounds` 的 direction `(0.03, 0.14, 1)`、occupancy `0.22`，目标与观察位置均上移 `0.15m`；通用总览算法未改变。

基准初始化（1440×810、无偏好）实测参数：

| 对象 | position | target / lookAt | FOV |
| --- | --- | --- | --- |
| 导演相机 | `[0.385188, 2.822543, 12.941136]` | `[0, 1.025, 0.101542]` | 40° |
| 主机位 | `[0, 1.55, 3.4344]` | `[0, 0.875, 0.101542]` | 48° |

画幅 `auto` 随实际视口；导演编辑态显式画幅同步视锥，普通播放仍为全视口。人物投影高度约 18.3%，脚底约 60.6%。补建场景回归 fixture 为 `e2e/fixtures/round4-default.json`。完整导出的默认场景及参数见 `test-output/round4/camera-parameters.json` 的 `seed` 字段（顶层 `director` 是路径测试结束后的观察相机，不是初始化相机）。

## 实现范围

- 时间轴无偏好默认关闭且高度为 0；既有展开偏好保留。对象选择与轨道展开解耦，默认三主行使用灰色/灰绿存在条、细路径线和“已设轨迹”。
- 六导航：场景、添加角色、添加机位、全景图、画幅、识图导入。道具与群众仍在“添加角色”菜单内。场景入口回到列表，标题栏负责折叠。
- AI 预制托盘锚定胶囊上方，宽 420px（受可用窗口宽度限制），高不超过 220px，两列卡片。预制仅填草稿，不发送；非空草稿需托盘内替换确认；生成模式清除旧图片。设置、历史与预制互斥。Esc、点击外部、Space、中文组合输入和取消沿用现有链路。
- 路径菜单通过 `pathMenu.js` 共用，时间轴绑定行实体 ID，打开/取消不改播放、视角、选择和文档。选类型后才暂停、切导演视角并进入统一 PathTool。
- 圆环使用原 arc 生成器的 360°闭合；原 arc/半环绕 API 保持。直线、铅笔、钢笔、走到/推到沿用现有工具。矩形使用局部 XZ 轴对齐四角、保留机位高度、闭合回起点，并拒绝过短边。
- 路径控制点只在明确编辑现有轨迹或完成绘制后显示。矩形预览/播放/编辑/导出共用 `Path`，采样包含精确角点，命中测试使用对应弧长。
- 机位视锥使用真实 FOV/aspect/世界位姿，长度取目标的前向深度并限幅；透明度 0.23、蓝灰细线，只保留 12 条视锥边。主机位或选中机位显示，其余按策略隐藏；播放、截图、导出沿用既有 clean-render 显隐。

## 文档与兼容性

`Path.interpolation` 是可选字段，允许 `centripetal` / `polyline`；缺省完全沿用原 centripetal。保持 `director-stage/0.1`，与既有可选 stops 字段扩展方式一致，不迁移旧路径数据。校验、Timeline 新增/更新、导入导出、历史、PathEditor 和 overlay 保留该字段。重新绘制为非矩形时清除旧 interpolation。旧版程序的严格校验器不认识此新增字段；含矩形的文件应使用本轮版本打开。

polyline 按真实边长求值，直角处切线可以突变，不承诺圆滑转角；已有 stops 仍可用于顶点停顿。钢笔仍是点选曲线，不是完整 Bezier 手柄编辑器。AI 的旧模式词汇和 ops 枚举没有扩展。
