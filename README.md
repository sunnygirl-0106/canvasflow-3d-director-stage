## ✨ 一个小舞台，装下你的镜头想法

3D 导演台是一款运行在浏览器里的分镜预演工具。你可以用它推敲人物站位、调整构图、尝试运镜，也可以把画面导出来，和伙伴一起讨论下一场戏。

- **🧍 摆角色，也摆姿势** — 多种体型可选，站立、挥手、抱臂、坐姿一键切换；想再细调一点，就用姿势面板调整关节。
- **🪑 搭个简单的场景** — 用方块、圆柱和球体布置空间，调整颜色与尺寸；人多的镜头可以直接添加群众阵列。
- **📷 找到喜欢的构图** — 添加机位、对准主体，切到机位视角看效果。横屏、竖屏、方形画幅，都可以试一试。
- **🚶 让角色走起来** — 画一条路径，角色便会沿着它移动；也可以安排中途停顿，用时间轴调整节奏。
- **🎞️ 给镜头一点运动** — 推、拉、横移、升降、摇镜头与环绕都已备好，还能把几段运镜接起来。
- **🌄 换一片天空** — 调整天空颜色，或载入全景背景，为场景添一点气氛。
- **🤖 请 AI 帮忙开场** — 用一句话搭场景、修改人物安排，或上传站位参考图，让 AI 帮你摆出初稿。
- **💾 留住这一幕** — 导出 PNG 分镜、MP4 视频，或保存场景文件，下次继续。操作也支持撤销与重做，放心多试几个版本。

## 🎬 先拍一个小镜头

打开 **[在线体验](https://sunnygirl-0106.github.io/canvasflow-3d-director-stage/)**，就可以开始，不需要先安装开发工具。

1. **请角色入场**：在底部工具栏添加角色，选中后到右侧「姿势」面板挑一个动作。
2. **摆好站位**：拖动角色身旁的彩色箭头调整位置，再放几个道具，交代一下空间。
3. **架起摄像机**：添加机位，切到顶部「机位视角」，调整到你喜欢的构图。
4. **让画面动起来**：给角色画路径，或在机位的「运镜」面板选择预设，点击「应用」。按空格播放看看。
5. **收工，保存！**：截一张分镜图；想留下动态片段，就选好时间轴里的「主机位」，从「场景」菜单导出视频。

> 小提示：想导出视频，请使用支持 WebCodecs 的 Chrome / Edge。视频在浏览器内生成，无需上传场景。

## 🤖 也可以先说一句话

点击底部工具栏的「AI」，在设置中填写模型接口地址、API Key 和模型名称，测试连接后就能使用。支持 OpenAI 兼容接口；识图需要模型支持图片输入。

不知道从哪里开始？试试这样的描述：

> 两个人在广场对话，一个女生站着挥手，一个男生坐着，镜头半环绕拍他们，5 秒。

场景生成后，还可以接着说：

> 让男生站起来，走到女生旁边，镜头改成慢慢推近。

也可以从左侧「预制场景」挑一个起点。点击后会先填入提示词，你可以改好再发送。生成新场景前会提示确认；对结果不满意，可以撤销这一轮，再换个想法。

**关于数据**：手动填写的模型设置保存在当前浏览器，不写入场景文件。使用 AI 时，提示词与场景摘要会发送到你配置的模型服务；识图时还会发送参考图片。普通摆景、截图和视频导出不需要连接模型。

## ⌨️ 几个顺手的小操作

| 操作 | 效果 |
| --- | --- |
| 在视口空白处拖动 | 环绕观察场景 |
| 滚轮 | 拉近 / 拉远视角 |
| 拖动对象旁的彩色控制柄 | 移动、旋转或缩放对象 |
| `V` / `R` / `S` | 切换移动 / 旋转 / 缩放 |
| `Space` | 播放 / 暂停 |
| `Esc` | 停止播放，回到起始状态 |
| `⌘Z` / `Ctrl+Z` | 撤销上一步 |
| `⇧⌘Z` / `Ctrl+Shift+Z` | 重做 |
| `Del` / `Backspace` | 删除选中的对象、关键帧或路径顶点 |

场景可以从左上角「场景」菜单导出为 `.json` 文件，再导入继续编辑。左侧场景栏会显示自动保存状态，展开可恢复上次场景、重试保存或手动导出。不同标签页的恢复点独立保留；重要的作品记得另存一份。

## 🚀 在本地运行

准备好 **Node.js 22.12 或更高版本**，在项目目录运行：

```bash
npm install
npm run dev
```

打开终端给出的本地地址即可。需要构建或预览发布版本时：

```bash
npm run build       # 构建到 dist/
npm run preview     # 预览构建结果
```

运行 `npm run check` 可执行静态检查、类型检查与单元测试。

## 🛠️ 舞台背后

项目基于 **three.js + Vite**，使用原生 JavaScript 与 ES Module 构建；视频由浏览器的 WebCodecs 编码，并通过 mp4-muxer 封装。

```text
src/
├─ app/         场景操作、保存与导出
├─ entities/    角色、道具、机位与群众
├─ anim/        时间轴、路径与运镜
├─ ai/          AI 场景生成与修改
├─ core/        3D 视口、选择与变换
├─ doc/         场景数据与校验
├─ rig/         骨骼与姿势
├─ ui/          面板、工具栏与交互
├─ util/        公共工具
└─ styles/      界面样式
```

部署配置见 [GitHub Actions 工作流](.github/workflows/deploy.yml)，推送到 `main` 后会自动构建并发布到 GitHub Pages。
